# Internet Routing Monitor

A routing investigation workspace with a layered route web, replay controls, and inspectable evidence. This first iteration uses deterministic synthetic fixtures; historical records and live capture are next. The build plan is in [plan.md](plan.md). With Node 22.12+ and pnpm installed, run `pnpm install` and `pnpm dev`; `pnpm test`, `pnpm build`, and `pnpm test:e2e` check the prototype.
